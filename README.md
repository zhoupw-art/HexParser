##  instructions
    The hexadecimal .TXT file received by the data analyst consists of a long string of hexadecimal characters.
    The software is designed to locate specific bytes starting from a designated frame header position. Once the frame header is identified,
    the software allows for the sequential inspection of characters at specific offsets relative to that header and
    supports searching in both forward and backward directions from the starting point. Additionally,
    the software supports endianness conversion (big-endian/little-endian) for two-byte and four-byte data, 
    as well as hexadecimal-to-decimal conversion; other data—such as single bytes or sequences exceeding four bytes—are displayed 
    as single-byte decimal values ​​and hexadecimal bytes.
    数据分析师接收到的十六进制.TXT文本文件,由一长串十六进制字符组成。该软件旨在从指定的帧头位置开始定位特定的字节。
    一旦识别出帧头，软件便允许按顺序检查相对于该帧头特定偏移量处的字符，并支持从起始点向前,后两个方向进行搜索。
    此外，该软件还支持双字节和四字节数据的大小端字节序转换以及十六进制转十进制计数功能；至于其他数据（如单字节或超过四字节的序列），
    则会以单字节的十进制计数和十六进制字节形式显示。
    يتلقى محلل البيانات ملف نصي بصيغة TXT سداسي عشري، يتكون من سلسلة طويلة من الأحرف السداسية العشرية. صُمم البرنامج لتحديد مواقع بايتات معينة بدءًا من موضع محدد في رأس الإطار. بمجرد تحديد رأس الإطار، يتيح البرنامج فحصًا متسلسلًا للأحرف عند إزاحة محددة بالنسبة لهذا الرأس، مع دعم عمليات البحث للأمام والخلف من نقطة 
    البداية. علاوة على ذلك، يدعم البرنامج تحويل ترتيب البايتات للبيانات ثنائية البايت ورباعية البايت، بالإضافة إلى تحويل العد من سداسي عشري إلى عشري؛ أما
    
    البيانات الأخرى (مثل البايت الواحد أو التسلسلات التي تتجاوز أربعة بايتات) فتُعرض كعدد عشري أحادي البايت وبايتات سداسية عشرية.
